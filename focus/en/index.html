How do I start?

On iPhone or iPad, allow Screen Time access, select websites and daily hours, then save. The same window repeats every day.

Can I add a website during a block?

Yes. Additions are saved for future days as well. Removing websites, changing hours, and turning the plan off inside Focus become available after the block ends.

Why are some blocked screens different?

Apple controls the system screen for manually entered addresses. Focus can show encouragement on its supported custom Screen Time shields, but cannot customize every system screen.

Does closing the app stop blocking?

On iPhone and iPad, Apple's Screen Time services enforce the saved plan while authorization remains active. On Mac, closing the window leaves Focus running; force-quitting the local proxy can interrupt browsing. Restore network settings inside Focus before removing the Mac app.

My connection needs checking

Confirm you are using the latest Focus version and read the connection status in the app. Contact support if an unselected website cannot load. On Mac, do not delete Focus while its proxy settings are still enabled.
